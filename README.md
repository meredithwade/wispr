# Flow for the WhatsApp economy

Concept prototype + one-page pitch: Wispr Flow tailored for WhatsApp sellers in Brazil and Indonesia.

Single self-contained file — no build step.

## Publish on GitHub Pages
1. Create a repo, add `index.html` and this README.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / root.
3. Your page is live at `https://<user>.github.io/<repo>/` in about a minute.
